# 炉线换配方后的异常证据与处置范围

这是用于工艺时序与批次质量分析的本地工作区。样例资料为合成数据，不代表真实生产或检测记录。工作区包含 Python 3.11+ 命令入口和 JSON 记录，可离线查看与核验。无第三方依赖。

## 运行

设置 `PYTHONPATH=src` 后：

```bash
python3 -m thermal-process-signals version            # 工作区版本
python3 -m thermal-process-signals report             # 中文当班分析报告
python3 -m thermal-process-signals report --json      # 同一份结论的结构化输出
python3 -m unittest discover -s tests -v              # 基线检查（47 个用例）
```

## 资料

`data/sample.json` 保存小型合成记录，顶层键分别为 sensors, process, reviews。

`data/shift_handoff.json` 保存两条炉线交班资料。测点是摄氏温度，`value: null` 表示设备未采到值；`phase` 分开记录预热、换配方和稳定过程。`reference_log` 是值班登记的参考候选日，不表示其中所有读数均已获认可，其中换配方前另有同一配方的试产记录。所有时间采用工厂本地时间，停留区间左闭右开。

`route_log.station` 的 `feed` 是共用进料点，其余为炉线；`corrects` 引用被更正的卡，`filed_at` 是值班获知时间，`start_slack_minutes` 表示开始时刻前后可能的分钟误差。隔离卡中的范围是开卡时记录的异常工况区间，不是批次的全部停留时间。抽检的 `begin`、`end` 是记录所覆盖的生产区间，不是抽检时间；`recorded` 是结论入账时间。

`data/rework_census.json` 是同班补收的校时和返工资料：`sensor_readings` 里是记录仪时刻，这部分读数按 `phase_log` 和对时资料归入现场阶段，不与同线同时刻的初步读数重复累计。`anchors` 为同一连续段内的对时参照，偏移按整分钟理解，边界含首尾；仪器重启会开始新的连续段，工单和转运单一直使用现场时间。`initial_counts` 对应本班原始批号。`material_moves` 的件数是本次从各来源搬出及送入的件数，未搬出的仍留在原箱；`records_origin` 表示能否将来源对到件，非是否登记原箱编号。`item_trace` 提供签认的批次子集在指定炉线上的实际经过区间；`complete_furnace_trace` 表示确认指定实物在该班仅经历本条所列炉线和区间。`rework_inspections` 只适用于本次检查的实物、原因和数量；不足整箱且没有逐件标识的，不代表可指定箱内哪几件。`available_checks` 是能补取的资料种类，尚无答案或抽检值。

## 分析模块（`src/thermal-process-signals/`）

| 模块 | 职责 |
| --- | --- |
| `baseline.py` | 按线/配方分别建控制基线；当班当天读数、预热/换配方段、无读数点不进基线；参考日异配方稳定块标为试产参考并声明覆盖缺口；样本不足标不可判断。 |
| `detect.py` | 稳定阶段越界检测：相邻越界点合并为持续偏移，单点为孤立尖峰，无读数单列；预期工况窗口只列示不报警；不按缺点数折算质量风险。 |
| `routing.py` | 改线卡取代原卡、开始时刻松弛、进料点不参与炉线判定；批次暴露分确已接触/仍可能接触/可排除三档；抽检按覆盖区间决定能否解除。 |
| `clock_sync.py` | 连续段内锚点求整分钟可行偏移交集，整段测点共用同一偏移；测点分为可确认异常、对时不确定、无读数三档；检测跨段表面报警在现场时刻的重合。 |
| `genealogy.py` | 拆箱/混装按件数守恒重放；混装失源后只做容器级候疑；签认完整炉线经历只排除卡上容器的未列炉线，禁止外推；返工抽检按覆盖件数决定解除。 |
| `ledger.py` | 只追加的处置台账：已发隔离/解除单不可改写；系统建议单带 `requires_confirmation`；新分析与旧决策冲突只产出再确认清单。 |
| `checks.py` | 评估重新校时、分箱交接核对、补做抽检各自能缩小的候疑范围和即使完成也解除不了的独立限制。 |
| `pipeline.py` / `report.py` | 总装管线与中文报告；JSON 输出与文本报告共用同一份结论。 |

## 关键判定口径

* 正常基线只使用截至当班已有的合格参考；处置后才确认的坏窗口不可能回流为训练数据。
* 两条炉线不合并均值；采样节奏不同的线各自确定窗口端点，缺测不折算风险。
* 同一批次的独立隔离理由分别计数，解除其中一条不恢复流转；解除提案必须有确认人。
* 对时只能给区间时，接触结论只能到“仍可能接触”，不填确切接触；批次经过时段用同一套可行对时判定。
* 已返工实物不撤回原批；无逐件去向的混装箱不能借同批另一只箱的签认卡放行。
